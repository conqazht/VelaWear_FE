## Why this matters

The README is still mostly the `create-next-app` template, advertises four
package managers and points to a page file that does not exist. At the same time,
the build-time `shadcn` CLI package is classified as a production dependency,
while the genuinely runtime `@shadcn/react` package must remain in production.
`AGENTS.md`, project status, and the integration convention also describe an old
prototype/API model. This plan makes onboarding reproducible with the repository's
actual pnpm/CI toolchain, classifies only the CLI dependency as development
tooling, and leaves one internally consistent documentation set.

network.
