## Why this matters

`MemberProfile` combines routing, auth gates, server queries, mutations, local
form state, five top-level tabs, five profile panels and four loading renderers
in one large file. Refactoring it without a behavioral safety net risks changing
query timing, form semantics or visible error states while producing a clean
diff. This plan first captures the merged behavior with semantic tests, then
extracts only pure utilities and loading UI so the later decomposition has a
stable baseline.

## Steps

### Step 1: Capture merged profile behavior before moving code

Extend `app/(shop)/profile/page.test.tsx` before extraction. Mock API-facing
hooks/providers but assert user-visible semantics and calls rather than component
internals or broad snapshots. Cover auth loading, guest gate, default account
view, query gates from FE-008, profile save success/failure, delivery loading/
error/empty/success, orders loading/error/empty/success, favorites loading/error/
success, valid URL tabs and invalid-tab fallback. Cover the FE-004 settings link
and absence/disabled state of unsupported settings without reintroducing them.

Run these tests against the still-monolithic file and commit only after they
pass. This creates the characterization baseline.

**Verify**: `pnpm exec vitest run "app/(shop)/profile/page.test.tsx"` → every
named behavior passes before extraction begins.

### Step 2: Extract pure profile formatters and metadata

Create `components/shop/profile/profile-formatters.ts`. Move `ProfileTabId`, tab
normalization, display/member date formatting, address formatting, order status
metadata, label-key mapping and status order when they remain pure. Preserve
exports as typed, deterministic functions/constants; do not add React, provider,
query or mutation dependencies. Update `page.tsx` imports without altering call
sites' semantics.

Create `profile-formatters.test.ts` for valid/invalid tabs, null/invalid dates,
locale-sensitive dates, sparse address fields and known/unknown order statuses.

**Verify**:
`pnpm exec vitest run components/shop/profile/profile-formatters.test.ts "app/(shop)/profile/page.test.tsx"`
